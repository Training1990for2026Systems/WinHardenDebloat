Optional: put Microsoft's PowerShell 7.6 (or a newer stable version) MSI file here,
named like  PowerShell-7.6.6-win-x64.msi  (or ...-win-arm64.msi on ARM PCs).
The starter can then install PowerShell 7 without winget and without internet.
It only uses a file with a valid Microsoft signature, and only after your yes.
