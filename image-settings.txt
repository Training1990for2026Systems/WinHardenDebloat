# WHD USB Image - settings that are written into the image before Windows is installed.
# Read by Apply-HomeImage.ps1. remove-list.txt says what is taken OUT of the image; this file says what is SET in it.
# This is an EXAMPLE: most of the machine-wide registry part of the WHD Classic "standard" profile. Change
# it to your own choice. What the profile does and this file does not is listed in README.md.
# A line that starts with # is a comment.
#
# Line types:
#   part:<name> on|off         a whole part of the work (the three parts are listed just below)
#   group:<name> on|off        starts a group; the reg: and service-off: lines below it belong to it
#   reg:<hive>|<key>|<value name>|<type>|<data>
#        hive  SOFTWARE or SYSTEM
#        key   for SOFTWARE: the key below HKLM\SOFTWARE
#              for SYSTEM:   the key below the control set (starts with Services\ or Control\)
#        type  dword (data = a whole number) or string
#   service-off:<service>      sets the service to "disabled" (Start = 4); skipped when it is not in the image
#
# Every value here is machine-wide (HKEY_LOCAL_MACHINE). Per-user settings are not in this file.
# Microsoft documents most of the policy values for Pro / Enterprise / Education. On Home they do no harm,
# but only a test install shows which of them Windows keeps to.
# WHD Classic and WHD Next do not know about values set here: their Undo, Verify and update guard work from
# their own change history. The file WHD-Image-applied.txt inside the image is the record of this run.

# ------------------------------------------------------------------------------------------------------
# The three parts
# ------------------------------------------------------------------------------------------------------
# machine-settings   the groups in this file
# removed-app-marks  for every app that remove-list.txt takes out, write Windows' "deprovisioned" mark,
#                    which tells Windows not to put that app back at a Windows update
# first-signin       copy first-signin\WHD-FirstSignIn.ps1 and first-signin-list.txt into the image, and the
#                    answer file as Windows\Panther\unattend.xml, so the script runs once at the first sign-in
part:machine-settings on
part:removed-app-marks on
part:first-signin on
